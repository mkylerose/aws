aws_list_instances.sh -- Lists all EC2 instances across regions with status and name tags.

aws_ec2_backup.sh -- Creates AMI snapshots of all running EC2 instances.

aws_s3_sync.sh -- Syncs a local folder to an S3 bucket with logging.

aws_cleanup_old_snapshots.sh -- Deletes EC2 snapshots older than X days.

aws_cost_report.sh -- Shows your last month's cost breakdown using Cost Explorer.

aws_rotate_keys.sh -- Rotates AWS IAM user access keys (and disables old ones).

aws_check_public_s3.sh -- Scans your S3 buckets for public access permissions.
